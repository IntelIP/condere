# Dossier and handoff

Use after evidence reconciliation. Read the preserved brief, accepted findings,
review qualifications, source index, cost status, and proposed next validation work.
The application renders JSON and Markdown from the same saved accepted records;
do not create a second competing answer set for a particular client.

Provide a concise recommendation and its practical meaning for the founder.
Include supporting and contrary evidence, remaining uncertainty, alternatives,
and the next useful decision. Preserve all Technical findings and all 17 complete
question records through retrievable sections/references. A short summary must not
discard details, references, qualifications, or unavailable findings.

The portable handoff contains original intent, constraints, relevant alternatives,
candidate architecture, known versions and licenses, evidence-backed technical and
business findings, assumptions, unresolved decisions, validation proposals, and
proposed implementation scope. Distinguish proposed design from verified technology
behavior and business hypotheses from measured results. Sources retain content
hashes and review status; unreviewed material is not an accepted finding.

State settled cost, pending charges, and cost-basis limitations accurately. Traces
are diagnostic observations rather than invoices or the authoritative spending
ledger. A missing trace does not imply a free operation.

Finish when the application validates coverage, references, required review, and
output consistency. Retrieval and export reuse saved results without another
research run or provider call. Delivering a handoff does not authorize building
the proposed product or making the user's decision.
