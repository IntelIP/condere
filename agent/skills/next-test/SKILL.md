# Next test

Write `next_test`: the critical assumption, a bounded method, observable success
and failure rules, and cost and time. Choose the uncertainty that matters most to
the decision, not the easiest one. A recommendation is not permission to run the
test: no outreach, purchases or posting.

Record material constraints that could make the opportunity unsuitable as claims
and, where a person must answer, as `open_questions` with `who_can_answer`.

`checklist.md` holds the preserved B4, B8 and B9 guides.
